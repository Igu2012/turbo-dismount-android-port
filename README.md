# Turbo Dismount fan port

This is a fanmade port of Turbo Dismount for modern Android devices.

It is not official, and I do not make money from it. Turbo Dismount and its original assets belong to Secret Exit Ltd. Please support the original game and its creators.

## Build

Open the project with Unity 2022.3.62f1. Install Android Build Support, SDK, NDK and OpenJDK, then open `Assets/Editor/PortBuild.cs` and run:

`Turbo Dismount Port > Build Android ARM64`

The build uses IL2CPP and ARM64.
